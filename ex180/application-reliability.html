Objective 4: Configure Applications for Reliability

EX180 — Health probes, compute capacity limits, and application autoscaling

In Preparation

This is an upcoming study guide for the EX180 exam objective. Content will be added soon.

Study Points for the Exam

  • Configure application health probes — Liveness probes (restart unhealthy pods), readiness probes (control traffic routing), startup probes (slow-starting containers)
  • Reserve and limit compute capacity for applications — Resource requests and limits (CPU, memory), ResourceQuota, LimitRange
  • Configure application autoscaling — Horizontal Pod Autoscaler (HPA), scaling policies, metrics
