Architecture & Fundamentals

Understand RHOAI's relationship with OpenShift, MLOps, GenAIOps, and key components

What is OpenShift AI?

Red Hat OpenShift AI (RHOAI) is a platform on top of OpenShift Container Platform that provides an environment to develop, train, serve, test, and monitor AI/ML models and applications on-premise or in the cloud.

RHOAI serves two primary user roles:

  • Data Scientists — Create projects, workbenches, notebooks, train models, deploy models, and build pipelines
  • Cluster Administrators — Install RHOAI, manage users, configure accelerators, manage resources

Relationship with OpenShift

RHOAI is an operator-based application deployed on OpenShift Container Platform. It leverages OpenShift's foundational capabilities:

  • Container Orchestration — Pods, Deployments, Services managed by OpenShift
  • Networking — Routes, Services, NetworkPolicies for model serving endpoints
  • Security — RBAC, Service Accounts, SAs, SecurityContextConstraints
  • Storage — PersistentVolumeClaims for model storage and data
  • Accelerators — GPU, CPU, and accelerator management via OpenShift

RHOAI is installed as an operator on OpenShift using the OperatorHub. Key components are deployed as CRDs (Custom Resource Definitions) in the openshift-ai namespace.

MLOps and GenAIOps

MLOps (Machine Learning Operations) covers the lifecycle of ML models from development to production:

  • Develop — Data preparation, model training in Jupyter workbenches
  • Validate — Model evaluation, bias detection with TrustyAI
  • Deploy — Model serving via KServe (Single-Model or Multi-Model platforms)
  • Monitor — Model performance, drift detection, hardware monitoring
  • Retrain — Automated pipelines with Elyra/Kubeflow

GenAIOps extends this to Generative AI:

  • RAG (Retrieval-Augmented Generation) pipelines
  • Agentic AI with tools and multi-step reasoning
  • Guardrails for content safety
  • LLM optimization (compression, quantization with LLM Compressor)

Data Science Projects

In RHOAI, a project (not an OpenShift project) is a logical grouping of workbenches, models, pipelines, and connections for a specific data science effort. Each project provides:

  • Workbenches (Jupyter notebooks)
  • Pipeline servers
  • Model serving runtimes
  • Model registry connections
  • Storage (PVCs)
  • Data connections (S3, database)
  • Accelerators

Projects are namespaced in OpenShift. The default namespaces created by OpenShift AI include redhat-ods-applications (dashboard components) and rhods-notebooks (workbenches).
