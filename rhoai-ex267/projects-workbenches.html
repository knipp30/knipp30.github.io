Data Science Projects & Workbenches

Create, configure, and manage projects, permissions, workbenches, and custom images

Creating and Managing Projects

Data Science Projects in RHOAI are a user-created organizational concept. They are NOT the same as Kubernetes/OpenShift projects (namespaces).

Steps to create a project via the UI:

  • Navigate to OpenShift AI Dashboard → Data Science Projects → Create Data Science Project
  • Enter a unique project name and description
  • RHOAI creates an underlying OpenShift project (namespace) automatically

Managing project members:

  • Open the project → Members tab
  • Add members by username (the username is the name you set for the user when creating the user)
  • Roles: Admin (full access) or Read-only

Permissions Model

Permissions in RHOAI are hierarchical:

  • Cluster Admin — Full OpenShift + RHOAI control
  • RHOAI Admin — Manage RHOAI settings, workbench images, dashboard config
  • Data Science Project Admin — Manage project resources, members
  • Project Member — Access to project resources
  • Read-only — View-only access

The admin role for a project has access to all project resources including workbenches, models, pipelines, and storage.

Creating Workbenches

Workbenches are JupyterLab or VS Code instances running in OpenShift pods.

Creating a workbench:

  • Open Data Science Project → Workbenches tab → Create Workbench
  • Name the workbench
  • Select IDE: JupyterLab or VS Code
  • Select a workbench image (default or custom)
  • Select size (CPU/memory): e.g., 4 CPU, 16Gi
  • Configure accelerator (GPU/CPU) if needed

Default workbench images include:

  • rohc-notebooks-jupyterhub — JupyterLab with Python 3.12 (various images available including CUDA, PyTorch, TensorFlow variants)
  • Various images with pre-installed ML frameworks (TensorFlow, PyTorch)

Custom Workbench Images

Data scientists can create custom images from existing ones:

# From a running workbench, create a custom image
# 1. Open the workbench → "Save as New Image" option
# 2. Or use CLI with ImageStream CRD:

# In JupyterLab, click File → New → Notebook to create from a workbench image
# Or create a custom image by running a workbench, installing packages,
# then using "Save as New Image" from the workbench controls

Importing custom images into RHOAI:

  • As a RHOAI admin: Resources → Cluster → Custom Workbench Images → Import Image
  • Specify the container image name and display name
  • The image becomes available when creating new workbenches

Workbench Sizes

Default size presets are defined as StorageSize and CpuMemorySize CRs:

# Default CPU/Memory sizes
apiVersion: dashboard.opendatahub.io/v1
kind: CpuMemorySize
metadata:
  name: xsmall
  namespace: openshift-ai-dashboard
spec:
  cpu: "0.5"
  memory: "2Gi"

Available sizes: xsmall, small, medium, large, xlarge

TensorBoard Integration

TensorBoard can be used for monitoring training processes:

  • Installed in workbench images by default
  • Start with: tensorboard --logdir=./logs
  • Access via port-forwarding or the workbench's built-in URL
  • Monitor training metrics, hyperparameters, model graphs

IDE Workspace Settings

Users can change their IDE workspace:

  • Click the gear icon (Settings) in the IDE
  • Navigate to Workspace settings
  • Change default file encoding, editor themes, etc.
