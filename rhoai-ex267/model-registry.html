Model Registry

Package, register, version, and deploy models as OCI artifacts

Model Registry Overview

The Model Registry in RHOAI provides version control for models. Models are stored as OCI image artifacts, enabling reproducibility and auditability.

Key concepts:

  • Model Registry — Central repository for model versions
  • Model Catalog — Pre-built models available for deployment
  • Artifact — An OCI image containing a model version
  • Stage — Development, Staging, Production

Enabling the Model Registry

Admin steps:

  • Set managementState: Managed for the modelregistry component in the DataScienceCluster CR
  • Configure the Model Registry CR with storage settings
  • Storage defaults to PVC; can also use S3 for production

Creating Model Registries

OpenShift AI administrators can create model registries from the dashboard. Data scientists with access can register, version, deploy, and track models.

Admin setup:

  • Enable Model Registry component in the DataScienceCluster CR
  • Data scientists can register models from the dashboard or Model Catalog

Registering and Versioning Models

Through the UI:

  • Open Model Registry → Register model
  • Enter model name, description
  • Enter version details: version name, model format (e.g., ONNX), format version
  • Specify model location: S3 connection details or URI
  • Models can also be registered directly from the Model Catalog

Model location types:

  • Object storage — Use an existing S3 connection or manually enter bucket/endpoint/path
  • URI — Direct URI for public OCI repositories

Deploying from Registry

Deploy models directly from the Model Registry:

  • Open Data Science Project → Models → Deploy Model
  • Select "Model Registry" as storage type
  • Choose the model and version from the registry
  • Configure serving parameters as usual

Model Registry API

The Model Registry exposes a REST API for querying models. The API endpoints are accessible via the Model Registry service route:

# Get all models
curl https://modelregistry-host/apis/metadata.googleapis.com/v1/projects/default/models

# Get model versions
curl https://modelregistry-host/apis/metadata.googleapis.com/v1/artifacts?parent=projects/default/models/model-name

# Get specific model version metadata
curl https://modelregistry-host/apis/metadata.googleapis.com/v1/artifacts/artifact-id
