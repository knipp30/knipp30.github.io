Data Connections

Create S3, database connections and manage data access for workbenches

Data Connections Overview

RHOAI Data Connections provide a way to connect to external data sources like S3-compatible object storage and databases. They abstract the credential management and connection details by storing parameters (access key, secret key, endpoint, region, bucket) securely.

Creating Connections

Steps:

  • Open Data Science Project → Connections tab → Create Connection
  • Select a connection type:

S3-Compatible Object Storage

  • Connection Type: S3-Compatible
  • Required fields:
    • Connection Name
    • Access Key / Secret Key (or IAM role for OpenShift-integrated storage)
    • Endpoint URL
    • Region
    • Bucket Name

Database Connections

RHOAI supports database connections for external databases such as MySQL, MariaDB, and PostgreSQL. Configure the connection with:

  • Connection name and type (MySQL, MariaDB, PostgreSQL)
  • Host, port, database name
  • Authentication credentials
  • Connection parameters (SSL, timeout, etc.)

Using Connections in Notebooks

Once created, connections are available in your workbench as environment variables. The exact variable names depend on the connection name you chose. For a connection named my-s3-conn, environment variables are prefixed with the connection name.

# Access S3 connection from environment
# Environment variable names depend on connection name
import os

# For an S3 connection named 'my-s3-conn':
# RHOAI_CONN_MY_S3_CONN_ACCESS_KEY
# RHOAI_CONN_MY_S3_CONN_SECRET_KEY
# RHOAI_CONN_MY_S3_CONN_ENDPOINT
# RHOAI_CONN_MY_S3_CONN_BUCKET

import boto3
s3 = boto3.client('s3',
                  aws_access_key_id=os.environ['RHOAI_CONN_MY_S3_CONN_ACCESS_KEY'],
                  aws_secret_access_key=os.environ['RHOAI_CONN_MY_S3_CONN_SECRET_KEY'],
                  endpoint_url=os.environ['RHOAI_CONN_MY_S3_CONN_ENDPOINT'])

Using IAM Roles with OpenShift

For OpenShift-integrated S3-compatible storage, you can use IAM roles instead of static credentials:

  • Create an IAM role in your S3 provider
  • Attach the role to the service account in the workbench's namespace
  • RHOAI automatically mounts the credentials as environment variables

Importing Data

Connect to data sources and import data for training:

# Read from S3
import pandas as pd
import boto3

s3 = boto3.client('s3', ...)
obj = s3.get_object(Bucket=bucket, Key='data/training_data.csv')
df = pd.read_csv(obj['Body'])
