GenAI Applications

Build RAG, streaming, agentic AI apps with guardrails

GenAI Application Patterns

RHOAI supports building Generative AI applications using several patterns:

  • Simple Prompt — Direct LLM queries
  • Streaming Responses — Token-by-token output for real-time UX
  • RAG — Retrieval-Augmented Generation with external knowledge
  • Agentic AI — Autonomous agents with tools and reasoning
  • Guardrails — Content safety and input validation

Simple GenAI Application

# Basic LLM interaction
from openai import OpenAI

client = OpenAI(
    base_url="https://<model-serving-endpoint>/v1",
    api_key="fake"  # No auth needed for in-cluster
)

response = client.chat.completions.create(
    model="llama-2-7b",
    messages=[{"role": "user", "content": "Explain quantum computing"}]
)
print(response.choices[0].message.content)

Streaming Responses

# Stream token-by-token for real-time UX
response = client.chat.completions.create(
    model="llama-2-7b",
    messages=[{"role": "user", "content": prompt}],
    stream=True
)

for chunk in response:
    token = chunk.choices[0].delta.content
    if token:
        print(token, end="", flush=True)

RAG (Retrieval-Augmented Generation)

RAG combines retrieval from a knowledge base with LLM generation:

# RAG pattern with vector database
from langchain.vectorstores import FAISS
from langchain.embeddings import HuggingFaceEmbeddings
from langchain.llms import VLLMOpenAI

# Load and embed documents
vectorstore = FAISS.from_documents(docs, embeddings)

# Retrieve relevant documents
similar_docs = vectorstore.similarity_search(query, k=3)

# Generate response with retrieved context
context = "
".join([d.page_content for d in similar_docs])
prompt = f"Context: {context}\nQuestion: {query}"
response = llm(prompt)

Key components:

  • Document processing — Chunk, embed, and index documents
  • Vector database — FAISS, Pinecone, Weaviate for similarity search
  • Retrieval — Find relevant context for the query
  • Generation — LLM generates response using retrieved context

Agentic Applications

Agents use tools and multi-step reasoning to accomplish tasks:

# Agent with tools
from langchain.agents import AgentExecutor, create_react_agent

tools = [search_tool, calculator_tool, database_tool]
agent = create_react_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

# Multi-step reasoning
result = executor.run("What's the weather in Chicago and should I bring an umbrella?")

Agent capabilities:

  • Tool use — Search, calculators, databases, APIs
  • Multi-step reasoning — Break complex tasks into steps
  • Memory — Short-term and long-term memory for context
  • Planning — Plan and execute multi-step workflows

Guardrails

Implement guardrails for content safety and input/output validation:

  • Input validation — Filter malicious prompts (injection attacks, PII)
  • Output filtering — Prevent generation of harmful content
  • Rate limiting — Prevent abuse
  • Context validation — Ensure retrieved context is relevant and accurate

Guardrail techniques:

  • Sentiment analysis on input/output
  • Keyword/regex blocking for sensitive data
  • Classification models for content moderation
  • Relevance scoring for RAG context
