Optimize & Evaluate Models

LLM Compressor quantization, LMEval benchmarks, model optimization strategies

Selecting Models

RHOAI provides access to pre-trained models through multiple sources:

  • RHOAI Model Catalog — Curated models from Red Hat, IBM, Meta, Nvidia, Mistral AI, Google
  • Hugging Face Hub — Thousands of community models (transformers, vision, audio)
  • Model Registry — Internal organization models

Hugging Face integration allows browsing and downloading models directly in the workbench:

# Download a model from Hugging Face
from transformers import AutoModelForSequenceClassification, AutoTokenizer

model_name = "distilbert-base-uncased-finetuned-sst-2-english"
model = AutoModelForSequenceClassification.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)

LLM Compressor (Quantization & Compression)

LLM Compressor is now generally available and fully integrated into standard OpenShift AI workbench images and pipelines. It reduces large language model size and improves inference performance.

Usage as a notebook task:

from llmcompressor.transformers import Compressor

# Compress a model
compressor = Compressor.from_trained(
    model=model,
    tokenizer=tokenizer,
    sparsity=0.5
)
compressed_model = compressor.compress()
compressed_model.save_pretrained('./compressed-model/')

Also available as a pipeline batch job for automated model optimization workflows.

Quantization types:

  • int8 — 8-bit integer quantization (best speed, slight accuracy tradeoff)
  • int4 — 4-bit integer quantization (max compression)
  • fp8 — 8-bit floating point
  • compressed_sparse — Sparse matrix compression

LMEval (LLM Evaluation)

LMEval is a TrustyAI-based feature for evaluating LLM performance against standard and custom benchmarks. It is a Technology Preview feature configurable through the DSC resource.

Standard benchmarks:

  • HellaSwag — Commonsense reasoning
  • PIQA — Physical commonsense reasoning
  • Winogrande — Coreference resolution
  • MMLU — Massive Multitask Language Understanding
  • TruthfulQA — Truthfulness evaluation

Custom benchmarks:

  • Define custom evaluation tasks with prompt templates
  • Use domain-specific test datasets
  • Custom metrics (F1, ROUGE, BLEU, custom scoring)

Administration: LMEval settings (allowOnline, allowCodeExecution) are configured through the DataScienceCluster resource's TrustyAI settings.

Model Evaluation Metrics

Classification: Accuracy, Precision, Recall, F1, AUC-ROC

Regression: MSE, RMSE, MAE, R²

LLM: Perplexity, BLEU, ROUGE, exact match
