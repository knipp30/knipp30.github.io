Git & ML Development

Version control notebooks, Python ML libraries, data loading, model export

Git Version Control in Jupyter

RHOAI workbenches support Git version control for notebooks:

  • Git extension is pre-installed in JupyterLab workbenches
  • Commit, push, pull, branch operations from the Git sidebar
  • Configure Git credentials in the workbench settings

Setting up Git:

# In the workbench terminal
git config --global user.email "user@example.com"
git config --global user.name "User Name"

# Add a remote
git remote add origin https://github.com/org/repo.git

# Configure credentials (use a personal access token)
git remote set-url origin https://user:TOKEN@github.com/org/repo.git

Git Workflow in Notebooks

  • Create notebook — New file in JupyterLab
  • Stage changes — Git sidebar → Stage file
  • Commit — Write message → Commit
  • Push — Push to remote repository
  • Branching — Create branches for experiments

Python ML Development

Train models using foundational ML libraries in Jupyter notebooks:

# Scikit-learn example
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
model = RandomForestClassifier(n_estimators=100)
model.fit(X_train, y_train)
print(classification_report(y_test, model.predict(X_test)))

Key libraries:

  • scikit-learn — Traditional ML (classification, regression, clustering)
  • TensorFlow / PyTorch — Deep learning
  • transformers (Hugging Face) — Pre-trained LLMs
  • pandas / numpy — Data manipulation
  • matplotlib / seaborn — Visualization

Loading Data Scalably

Large datasets:

# Dask for out-of-core computation
import dask.dataframe as dd
df = dd.read_csv('s3://bucket/large-dataset/*.csv')
model = dask_ml.wrappers.SGDClassifier().fit(df[X_cols], df[y_col])

# Vaex for memory-efficient DataFrames (available in custom images)
import vaex
df = vaex.open('dataset.hdf5')  # Lazy loading

Note: Dask and Vaex may require custom workbench images — they are not included in the default minimal workbench images.

Saving and Exporting Models

# Scikit-learn
import joblib
joblib.dump(model, 'model.joblib')
model = joblib.load('model.joblib')

# TensorFlow
model.save('my_model/')  # SavedFormat

# PyTorch
torch.save(model.state_dict(), 'model.pt')
model.load_state_dict(torch.load('model.pt'))

# ONNX (for deployment)
import onnxruntime
torch.onnx.export(model, x, 'model.onnx')

# MLflow
import mlflow
mlflow.sklearn.log_model(model, 'model')
