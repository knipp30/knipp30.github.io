Study Points for the Exam

1. Run Containers Locally Using Podman

# Run an interactive container
podman run -it alpine sh

# Run a detached container
podman run -d --name myweb nginx

# Run with port mapping
podman run -d -p 8080:80 --name myweb nginx

# Run with a volume mount
podman run -d -v /host/data:/container/data:Z myimage

Key flags:

  • -d: Run in detached mode (background)
  • -it: Interactive mode with tty
  • --name: Assign a name to the container
  • -p host:container: Map host port to container port
  • -v host:container:options: Bind mount
  • --rm: Automatically remove container when it exits

2. Get Container Logs

# View logs for a specific container
podman logs myweb

# Follow logs in real time
podman logs -f myweb

# Show only tail of logs
podman logs --tail 50 myweb

# Show timestamps
podman logs --since 2h myweb

3. Listen to Container Events on the Container Host

# Listen to container events
podman events myweb

# Filter by event type
podman events --filter event=start --filter event=stop

Common events: attach, detach, destroy, exec_create, exec_detach, exec_start, kill, mount, oom, pause, rename, resize, restart, start, stop, unmount, unpause

4. Use Podman Inspect

# Inspect a container
podman inspect myweb

# Inspect an image
podman inspect nginx

# Get specific fields
podman inspect --format '{{.Config.Hostname}}' myweb
podman inspect --format '{{.NetworkSettings.IPAddress}}' myweb

# Inspect in JSON format
podman inspect myweb | jq '.[0].Config.Env'

5. Specifying Environment Parameters

# Set environment variables at runtime
podman run -e APP_ENV=production -e DB_HOST=db.example.com myimage

# Read from a file
podman run --env-file ./env.list myimage

# Override ENV set in the image
podman run -e APP_ENV=development myimage

6. Expose Public Applications

# Expose a container port on the host
podman run -d -p 80:80 --name webserver nginx

# Expose on a specific host IP
podman run -d -p 127.0.0.1:8080:80 --name webserver nginx

# Expose multiple ports
podman run -d -p 80:80 -p 443:443 --name webserver nginx

# Use host networking (container shares host network namespace)
podman run -d --network=host nginx

7. Get Application Logs

# View stdout/stderr from the container
podman logs myapp

# Follow the log stream
podman logs -f myapp

# Filter by time
podman logs --since 2026-01-01T00:00:00 myapp

8. Inspect Running Applications

# List running containers
podman ps

# List all containers (including stopped)
podman ps -a

# View resource usage
podman top myapp

# Execute a command in a running container
podman exec -it myapp sh

# View container state and details
podman inspect myapp
